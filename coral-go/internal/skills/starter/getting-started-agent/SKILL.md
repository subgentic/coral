name: getting-started-agent
description: "How to guide a new user through Coral with a single agent when they request the Getting started tour."
metadata:
  published-by: Coral
  kind: example
---

Guide me through Coral as a first-time user. Lead one small step at a time. Wait for my answer or action before continuing. Use plain words and explain unfamiliar labels. When you ask me something with a few answers, give them as buttons, never as a typed list. Every step that waits on me ends with buttons too, never plain chat like "tell me when you're done": ask with `coral-agent ask "<the one thing to do now>" --option "Done" --option "Skip this step" --option "Stop the tour"` and stop until my answer arrives.

Start with these two lines:
Coral is a workspace where you give AI agents work and follow their progress.
You can answer questions, review files, and guide the work from one place.

Ask what I would like to make using `coral-agent ask "What would you like to make?" --option "A short report" --option "A simple spreadsheet" --option "A project plan"`. Tell me where to look: the Inbox tab at the top left of Coral, then Needs you, the first item in the list on the left. In two or three plain sentences say what Needs you is for (everything an agent needs from me waits there, so I never have to watch a terminal), what I will see (your question as a card with the buttons), and what to try (click one of the buttons, or type my own idea). Say in one line how to get any agent to do this again: ask it to ask me with buttons, and it will use `coral-agent ask --option`. Stop until my answer arrives. If that command is unavailable, explain that this tour needs a newer Coral and pause.

Create a small sample file related to my answer, using sample information only. Markdown can show pictures, so the first file you send must include at least one image you make for it, such as a small chart or diagram, with no real data and nothing downloaded: write a small SVG, base64-encode it on one line, and put it in the file as `![A small chart](data:image/svg+xml;base64,<the base64 text>)`. Coral shows that picture inside the file. Say in one line that I can ask any agent to put an image in the file it sends me. Upload it with `coral-agent artifact upload <file> --tag "for review" --question "Does this sample look right?"`. Give me the returned Coral link. Walk me through it one action at a time, and for each say in two or three plain sentences what it is for, what I will see and what to try. Opening the file: it appears in Needs you as a row with a button to open it; the file opens in a reader with its picture. Adding a comment: select some text in the file, choose the Add comment button that appears, write a note and save it; it shows in the Comments panel beside the file. Send to agent: a button on my comment that invites you to answer it; it is optional, and your reply appears under my comment. Approve or Request changes: the buttons at the top right of the file; Approve says it is good, Request changes asks for a new version with a note. After each, say in one line how to get any agent to do it again: ask it to put a file in Needs you for review (`coral-agent artifact upload <file> --tag "for review"`), to read my comments, and to answer Send to agent. Explain that Send to agent asks you to respond; it is optional. Tell me the Approve and Request changes buttons are on the file itself (the file's own page, not in this chat), and that I can use them or the buttons you ask with. Respond to my feedback and wait for my review before moving on. When you change a file I reviewed, upload the new copy with `--new-version-of <digest of the earlier upload>` (the last part of its link), never as a separate file, so my comments and what changed stay with it. Say in one line that I can ask any agent to "upload it as a new version" to keep the history.

Point out Analytics: the Analytics tab in the row of tabs along the top of Coral. Say in two or three plain sentences that it shows how much work your agents have done and what it cost, what I will see (charts and totals over time) and what to try (open it and look at the most recent days). Point out Settings: the gear icon at the top right of Coral. Say in two or three plain sentences that it holds my preferences, such as which agent new agents start with and how Coral looks, and that changing one is safe and takes effect right away unless it says otherwise. Invite me to open each; after each, ask with the Done / Skip this step / Stop the tour buttons and wait.

Finish by asking what real work I want to start (with `coral-agent ask ... --option` buttons for the likely choices, up to 3). Let me skip or stop the tour at any time.
