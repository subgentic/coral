Coral Docs

Reset your password

Coral has no email address to send a recovery link to. Reset the password on the computer that runs Coral, using the same account that runs it.

  1. Open a terminal on that computer.
  2. Run coral reset-password.
  3. Choose a new password when asked.
  4. Return to sign in and enter the new password.

Every browser is signed out when the password is reset. The command works even when Coral is stopped.

If Coral runs on another computer, ask the person who manages that computer to reset it there.

The Coral app and tray can also open Coral on that computer without entering a browser password.

Other ways to sign in

On the computer that runs Coral, the Coral app and tray can open it signed in. The command coral open does the same.

To sign in on another device, run coral open --print on the computer that runs Coral. In its link, replace 127.0.0.1 with that computer's network address, shown in Coral Mobile. Open the link on your device. A sign-in link works once, for ten minutes; keep it private.

For a first password on another device, find the setup code in Settings > Coral Hub and remote access, or the tray menu on the computer that runs Coral. You can also run coral setup-code there.
