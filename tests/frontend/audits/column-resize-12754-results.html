Column resize implementation · #12754

Base: 30df0983f. Audit: 27 modules / 39 shared table call sites; zero legacy dashboard table builders. All 16 desktop one-line table definitions now explicitly enable shared resize; the phone-only Analytics helper remains the intentional exception. Single-column lists and fixed/last-column edges retain their established exclusions.

What changed

One-line tables can use the shared drag and keyboard separators, fit to content, guarded browser-width storage, and existing column drop priorities. Each disabled production table is enabled in its own commit. The run tables also exposed an existing ambiguity between row identity and the explicitly growing column: the width engine now uses that explicit fill column consistently for layout and persistence. On phones, the original one-line/mail/card representation stays and resize handles are hidden, including coarse-pointer landscape phones.
